## 下载

- **安卓：下载 `tongjitap.apk`，安装后打开“循济”。** 可覆盖更新 0.2.0 和 0.2.1，保留点击配置。基础点击和音乐支持 Android 8+，颜色检测和跃点需要 Android 11+。
- **苹果：暂无 iOS 安装包。**
- 源码 ZIP 和 SHA-256 校验文件不需要安装。
