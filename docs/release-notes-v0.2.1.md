## 下载

- **安卓：下载下方 `tongjitap-0.2.1.apk`，安装后打开“循济”。** 可覆盖更新 0.2.0，保留已有设置。基础点击需要 Android 8+，颜色触发需要 Android 11+。
- **苹果：暂无 iOS 版。**
- `TongjiTap-0.2.1-source.zip` 是源码，普通用户不用下载；`.sha256` 是校验文件。
