# Tongji TapLoop v0.1.0

首个公开发布的离线 Android 点击序列辅助工具。项目中文名为“轻循”；本次安装包保留已验证的 0.1.0 构建，界面与辅助功能服务仍显示初始名称“轻点助手”。

## 下载与安装

下载 `lighttap-0.1.0.apk` 及对应 `.sha256` 文件，适用于 Android 8.0 及以上。首次使用需要阅读说明，并由用户自行开启辅助功能。请先在无重要数据的页面校准坐标。

源码请优先下载本页附件 `Tongji-TapLoop-0.1.0-source.zip`，其中包含公开发布时补齐的中英文 README、Apache-2.0 许可证和截图。APK 保持原始已验证构建不变；历史 `v0.1.0` 标签及 GitHub 自动生成的标签源码归档保留发布前的文档快照。

## 已包含的功能

- 多步骤坐标点击、可配置按住时长、释放后等待和有限次数整组循环。
- 屏幕取点、手动编辑、步骤排序和单组本地保存。
- 可见的悬浮控制面板、3 秒倒计时和异常停止。
- 离线运行，无广告、统计或账号登录，提供完整用途与风险说明。

## 验证范围

已记录 10 项核心单元测试和两个 Android 模拟器上的 22 项场景通过；签名 APK 在 Android 8.0 和 Android 16 模拟器上通过冷安装、主动确认和启动检查。真实手机、厂商后台策略及微信小程序尚未验证。
