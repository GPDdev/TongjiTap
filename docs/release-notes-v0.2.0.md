## 下载

- **安卓：下载下方 `tongjitap-0.2.0.apk`，安装后打开“循济”。** Android 8+ 可用，颜色触发需要 Android 11+。
- **苹果：暂无 iOS 版。**
- `TongjiTap-0.2.0-source.zip` 是源码，普通用户不用下载；`.sha256` 是校验文件。

## 这次更新

- 正式更名为 **循济 / TongjiTap**，换上统一的新图标。
- 蓝色按钮可操作，灰色按钮不可用。
- 新增颜色触发：检测到指定颜色后，点击指定位置或按返回，画面恢复后继续。
- 悬浮面板可直接选取检测点和动作点。

应用 ID 已改为 `org.hachile.tongjitap`，请作为新应用安装，重新开启辅助功能并设置步骤。
